Sign in

There is no account here. You "sign in" by supplying the API credentials this app acts with — they stay in your browser and are sent only to DigitalOcean and to your own Tailscale proxy.

Why a proxy? DigitalOcean's API sends CORS headers, so this page calls it directly. Tailscale's API sends none, so no browser can reach it from a web page. The proxy in apps/web/proxy/ forwards just the four Tailscale endpoints yVPN needs. Deploy it once, paste its URL here.

Nodes are DigitalOcean droplets tagged yVPN. Tailnet columns come from your Tailscale proxy and are matched to droplets by name.

New exit node

Pick a datacenter. A droplet is provisioned there, joins your tailnet with a single-use ephemeral key, and is enabled as an exit node.

Delete exit node

The droplet is destroyed immediately and billing stops. The matching machine stays in your tailnet until Tailscale reaps it — ephemeral nodes disappear on their own.
